# موقع سهرة عيد الميلاد · Full Volume Events by Louis

النسخة 2 من الموقع: نفس الشكل والألوان، العربي هو الأساس، والحجز بيوصل على واتساب.

## كل التعديلات بملف واحد

افتح `lib/event.ts` وعدّل منه كل إشي:

| بدك تغيّر | عدّل |
|---|---|
| طاولة انحجزت | ضيف رقمها لـ `bookedTables`، مثلاً `[3, 5]` |
| السعر | `pricePerGuest` |
| طريقة الحساب | `pricingMode`: `"whole-table"` الطاولة كاملة، أو `"per-seat"` حسب العدد |
| الطاولات ومكانها بالخريطة | `tables` |
| رقم واتساب | `contact.whatsapp` و `contact.phoneDisplay` |
| صور الفنانين | حط الصورة بمجلد `public/artists/` واكتب مسارها بـ `photo` |
| صورة القاعة | `venue.photo` |
| لقطات من حفلات سابقة (صور وفيديو) | حطها بمجلد `public/media/` وضيفها لـ `gallery`. القسم بيظهر لحاله لما تضيف أول لقطة |
| فيديو ورا العنوان | `heroVideo` و `heroPoster` (mp4 قصير بدون صوت، أقل من 5 ميغا) |
| الفيديو الكامل بقسم لقطات | `reel` (null = بدون) |
| المعلومات الناقصة (الدفع، الأولاد، وقت الخلصة…) | `details`. أي وحدة `null` بتضل مخفية |
| فنادق | `hotels`. إذا فاضية قسم الإقامة بيختفي |
| Meta Pixel | `metaPixelId` |
| Google Analytics | `googleAnalyticsId` |
| دومين جديد | `siteUrl` |

## كيف بيشتغل الحجز

الزائر بيختار عدد الأشخاص والطاولة، وبيكتب اسمه ورقمه. بعدها بينفتح واتساب ورسالة الحجز جاهزة لرقم لويس، والزائر بيكبس إرسال. الحجز ما بيتأكد إلا لما لويس يرد عليه. وكل ما تنحجز طاولة لازم تنضاف لـ `bookedTables` عشان تبين "محجوزة" بالموقع.

## التشغيل

```bash
npm install
npm run dev      # للتجربة على http://localhost:3000
npm run build    # بناء النسخة النهائية
npm start        # تشغيل النسخة النهائية
```

## النشر على DigitalOcean (نفس الموقع القديم)

1. ارفع المجلد على مستودع GitHub، أو بدّل محتوى المستودع القديم فيه.
2. بـ DigitalOcean App Platform الإعدادات بتضل زي ما هي: Build Command `npm run build` و Run Command `npm start`.
3. أي تعديل بتعمله على `lib/event.ts` وبترفعه، الموقع بيتحدث لحاله.

## الصور والفيديوهات

- الأفضل تاخدها أصلية من لويس وزهير، مش منزلة من إنستغرام، عشان الجودة. وخد موافقتهم على النشر.
- حجم الصور: 1200 بكسل عرض بيكفي. حوّلها لـ webp أو jpg مضغوط.
- الفيديو: mp4 من 5 لـ 15 ثانية، بدون صوت، أقل من 5 ميغا.

## الحركات

- أول شاشة: العناصر بتطلع بالترتيب، و"عيد الميلاد" فيها لمعة ذهبية، وفي ثلج وذرات ذهبية نازلة.
- شريط كلمات متحرك تحت أول شاشة.
- الأقسام بتطلع بحركة ناعمة مع السكرول.
- الفنانين: أسطوانة بتلف للدي جي، مايك بينبض للمطرب، وموجات صوت. ولما تنحط الصور بتتحرك بزوم بطيء.
- لقطات: شريطين صور بيتحركوا عكس بعض.
- الطاولات بتنط لما تختار العدد، والطاولة الأنسب بتلمع.
- إذا الجهاز مضبوط على "تقليل الحركة"، كل الحركات بتوقف لحالها.

## الملفات الحالية بـ public

- `artists/louis.webp` و `artists/zuhair.webp`: صور الفنانين، مقصوصة دائرية ومعدّل لونها.
- `media/hero-loop.mp4`: 11 ثانية من آخر فيديو لويس (الأضواء)، بتلعب ورا العنوان بدون صوت (1.4 ميغا).
- `media/louis-reel.mp4`: فيديو لويس كامل بصوت، 84 ثانية (7.6 ميغا).
- `media/moment-1..12.webp`: لقطات من الفيديو لقسم "لقطات".
